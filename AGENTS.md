Goal:

Tech:
- Kotlin
- Wear OS
- Jetpack Compose for Wear OS
- Health Services for workout/heart-rate data
- Keep implementation simple and incremental

Rules:
- Do not add features beyond the requested task.
- Before coding, inspect the existing project structure.
- Prefer small, testable changes.
- Explain which files changed and why.
- Do not invent APIs. If unsure, leave TODO and explain.
- Keep UI readable during swimming: very large text, high contrast, minimal controls.

General Rules

- Never invent Android APIs.
- Never invent Samsung APIs.
- If uncertain, leave a TODO.
- Prefer official Android APIs.
- Build one feature at a time.
